# Cybersecurity Deep Research

Research blueprint of ten technically rigorous problem statements across threat intelligence, incident response, digital forensics, vulnerability management, malware/ransomware analysis, AI in cybersecurity, XDR, CTEM, SIEM and defender AI.

Start with [`cybersecurity_deep_research/problem_statements.md`](cybersecurity_deep_research/problem_statements.md).

```
cybersecurity_deep_research/
  problem_statements.md      # 10 problem statements, 8 sections each (final output)
  gap_analysis_matrix.md     # Phase 3: silos/noise, adversarial mechanisms, scaling failures
  industry_telemetry/        # per-domain industry evidence logs (01..10)
  academic_gaps/             # per-domain academic evidence logs (01..10)
  extracted_evidence/
    evidence_ledger.md       # every claim with ID, source, URL, verification level
    research_log.md          # method, access limitations, verification TODO
```
